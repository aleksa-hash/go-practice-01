## Запуск первой программы

Откройте терминал в папке проекта, где находятся `main.go` и `go.mod`.

```text
go run .
Привет! Это моя первая программа на Go.
```
## Дополнительные программы

Команды запуска карточки и конвертера из корня проекта:
```text

go run ./cmd/card
```
